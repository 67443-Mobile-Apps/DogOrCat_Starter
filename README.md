Dog Or Cat App: Starter
---

This is the starter code for the DogOrCat app demonstrated in class.  To make this work, you need to first build a `DogCat.mlmodel` and add it to the project.  This can be build using the Create ML tool in Xcode and using the photo data found [here](https://www.microsoft.com/en-us/download/details.aspx?id=54765).
